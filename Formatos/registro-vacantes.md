# Formato de registro de vacantes

Este formato permite organizar la información de los cargos disponibles en una empresa.

| Campo | Información |
|---|---|
| Nombre del cargo |Auxiliar de Recursos Humanos|
| Área de trabajo |Gestión del Talento Humano|
| Número de vacantes |2|
| Nivel de formación requerido |Técnico o tecnólogo en gestión del talento humano o áreas administrativas |
| Experiencia solicitada |6 meses de experiencia en procesos administrativos o de selección |
| Competencias requeridas |Comunicación asertiva, organización, trabajo en equipo, responsabilidad y manejo de herramientas ofimáticas |
| Funciones del cargo |Apoyar la recepción de hojas de vida, revisar perfiles de candidatos, organizar entrevistas, actualizar bases de datos y realizar seguimiento a los procesos de selección |
| Fecha de publicación | 20/09/2026|
